# 统一记录微博接口

# 检索指定日期范围内微博

Get方法

功能说明: 可以通过该接口，对指定日期范围内的微博进行检索，示例参数为2017年1月1日至2017年2月1日

链接参数 : https://weibo.com/ajax/statuses/searchProfile?uid=1433680664&page=1&starttime=1483200000&endtime=1485964800&hasori=1&hasret=1&hastext=1&haspic=1&hasvideo=1&hasmusic=1

响应值示例: [示例](./返回值示例json/ajax/statuses/searchProfile.json)

curl示例
```bash
curl --url 'https://weibo.com/ajax/statuses/searchProfile?uid=1433680664&page=1&starttime=1483200000&endtime=1485964800&hasori=1&hasret=1&hastext=1&haspic=1&hasvideo=1&hasmusic=1' \
  -H 'accept: application/json, text/plain, */*' \
  -H 'accept-language: zh-CN,zh;q=0.9,en;q=0.8' \
  -H 'cache-control: no-cache' \
  -H 'client-version: v1.1.238' \
  -b '这部分是cookie，略过' \
  -H 'dnt: 1' \
  -H 'pragma: no-cache' \
  -H 'priority: u=1, i' \
  -H 'referer: https://weibo.com/u/1433680664' \
  -H 'sec-ch-ua: "Not=A?Brand";v="99", "Google Chrome";v="151", "Chromium";v="151"' \
  -H 'sec-ch-ua-mobile: ?0' \
  -H 'sec-ch-ua-platform: "Windows"' \
  -H 'sec-fetch-dest: empty' \
  -H 'sec-fetch-mode: cors' \
  -H 'sec-fetch-site: same-origin' \
  -H 'server-version: v2026.08.12.1' \
  -H 'user-agent: 这部分是ua，略过' \
  -H 'x-requested-with: XMLHttpRequest' \
  -H 'x-xsrf-token: 这部分是xsrf-token，略过'
```

注: 如果微博字段中，`isLongText`为true，需要额外获取长文本对应的微博内容

# 根据mblogid字段，获取实际文本

Get方法

功能说明: 长文本默认只返回概要，需要通过该接口，获取实际内容

链接参数 : https://weibo.com/ajax/statuses/longtext?id=Et6HUsgZr

响应值示例: [示例](./返回值示例json/ajax/statuses/longtext.json)

如果是markdown格式，响应值示例: [示例](./返回值示例json/ajax/statuses/longtext-markdown格式.json). 返回的长文本内容为markdown格式。需要渲染成html后展示。微博使用的markdown渲染css在[这里](./微博辅助css/markdown渲染用.css)
